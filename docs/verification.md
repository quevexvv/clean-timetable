# Проверки версии 0.1.0

Дата: 2 ноября 2026. Данные расписания могут обновляться независимо от расширения.

## Автоматические проверки

`npm test`: 24 поведенческие проверки через `node:test` и jsdom. Проверяются область постоянного правила, разовые пропуски, восстановление поверх правила, независимость групп и преподавателей, даты, последовательная запись, ошибки чтения/записи, проверка отправителя сообщений, расшифровка после загрузки, повторное построение таблицы и скрытие одного преподавателя под общим заголовком.

HTML-примеры реальных недель: `tests/fixtures/tpu-week10.html` и `tpu-week11.html`. Исходные страницы скачаны с сайта; читаемые названия сверены с DOM после штатной расшифровки в браузере. Удалены скрипты, внешние ресурсы и технические метаданные, сохранена структура таблицы.

- Неделя 10, 2–7 ноября: распознаются 30 занятий.
- Неделя 11, 9–14 ноября: распознаётся 31 занятие. В том числе два преподавателя лабораторной по физике под общим заголовком; скрытие одного не затрагивает другого.
- Постоянное правило для практики английского у Макаровских совпадает с двумя занятиями на неделе 10 и тремя на неделе 11. Разовый пропуск с недели 10 на неделе 11 не действует.

`npm run check` проверяет синтаксис JS. `npm run lint` использует `web-ext` с ошибкой при любом предупреждении. `npm run build` собирает только содержимое `extension/`, без тестов, инструментов и документов.

Итог: 24/24 теста прошли, синтаксис корректен, lint — 0 ошибок / 0 предупреждений / 0 замечаний, ZIP собран. Повторная установка зависимостей из lockfile проверена командой `npm ci --ignore-scripts --offline --no-audit --no-fund` с локальным кешем; удалённый CI не запускался.

## Проверка интерфейса

В управляемом браузере на локальном стенде с разметкой ТПУ и CSS сайта проверены:

- меню «Настроить» и подтверждение точного постоянного правила;
- скрытие двух лабораторных ОС у Цапко без скрытия соседних предметов;
- отсутствие разделителя и вертикальное центрирование оставшегося занятия;
- показ скрытых занятий в полном виде и возврат одной лабораторной;
- сохранение результата после перезагрузки страницы;
- применение того же правила на соседней неделе: после возврата одной пары недели 10 остаётся скрыта одна пара, на неделе 11 скрыты две.

Этот стенд использовал адаптер localStorage вместо WebExtensions API. Он проверяет DOM и интерфейс, но не доказывает работу установленного расширения на живом сайте. `preview.jpg` — снимок строки 12:40 после скрытия ОС у Цапко: Ковин остаётся по центру своей ячейки.

## Загрузка в целевые браузеры

Через `web-ext run` в отдельных временных профилях успешно загружено неподписанное дополнение:

- Firefox **159.0**, официальный Linux-пакет Mozilla;
- Zen **1.24b**, Gecko **159**, исполняемый файл установленного Flatpak.

Оба запуска сообщили `Installed … as a temporary add-on`. Основные профили пользователя не изменялись. Это подтверждает загрузку дополнения; ручные действия в установленном расширении на живом сайте через эти браузеры не проверены. Объявленный минимум Firefox 142 не проверен отдельным запуском.

## Осталось подтвердить

- Сквозные сценарии в постоянно установленном подписанном дополнении в Firefox и Zen на живом сайте.
- Сохранение правил после настоящего перезапуска браузера с постоянной установкой.
- Подпись Mozilla; удалённый запуск CI после помещения проекта в репозиторий.

Для окончательной проверки: установить подписанный XPI, скрыть лекцию у одного преподавателя, убедиться в видимости практики и другого преподавателя, перейти на соседнюю неделю, вернуть одно занятие, перезапустить браузер и проверить те же правила. При сохранении после обновления дополнения держать прежний ID.
