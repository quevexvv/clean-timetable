# Установка в Firefox и Zen

Версия для Chrome, Edge, Brave, Opera, Vivaldi и Яндекс Браузера собирается отдельно и устанавливается из `dist/chromium`; см. [chromium.md](chromium.md).

## Проверить текущую версию

1. Используйте ZIP `dist/tpu-schedule-filter-0.1.0.zip`. Для Zen из Flatpak скопируйте его в папку «Загрузки».
2. Откройте в нужном браузере `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» / «Load Temporary Add-on» и выберите ZIP. При разработке вне Flatpak также можно выбирать `extension/manifest.json` из папки проекта.
4. Откройте или обновите расписание группы на [my-rasp](https://my-rasp.tpu.ru/gruppa_44510/2026/11/view.html) или [ro-rasp](https://ro-rasp.tpu.ru/gruppa_44510/2026/11/view.html). Над таблицей появится «Моё расписание», а у пар — «Настроить».
5. Для собственной группы используйте её обычную ссылку. Правила одной группы действуют на обоих сайтах, правила разных групп независимы.

Отдельной кнопки расширения на панели инструментов нет. При установке предоставляется доступ к страницам расписаний групп ТПУ и локальному хранилищу. При отключённом доступе к сайту включите его в настройках дополнения. Названия пунктов в Zen могут отличаться.

Временная установка сохраняется **только до перезапуска браузера**. Поведение хранилища временных дополнений отличается от постоянных: не используйте его как проверку сохранности правил после удаления/повторной загрузки.

Источник: [Temporary installation in Firefox](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

## Zen из Flatpak: дополнение загрузилось, но панели нет

Файловый портал может предоставить доступ только к выбранному `manifest.json`, не ко всей папке расширения. В проверенной установке Zen 1.24b каталог проекта в `~/Projects` был недоступен из песочницы; ZIP в папке «Загрузки» читался. Пользователь подтвердил работу после загрузки архива.

Загрузите ZIP из «Загрузок» через «Загрузить временное дополнение» и обновите вкладку расписания. Архив содержит все необходимые JS/CSS; расширять разрешения Flatpak для этого не требуется. Если панель по-прежнему не появилась, проверьте доступ дополнения к сайту и его ошибки в `about:debugging`.

## Постоянная установка

Для обычного Firefox нужен подписанный Mozilla пакет. Можно получить подпись **без публичного размещения в каталоге**, выбрав самостоятельное распространение (unlisted).

1. Соберите пакет командой `npm run build` или используйте ZIP из `dist/`.
2. Войдите в [Mozilla Add-on Developer Hub](https://addons.mozilla.org/developers/) под своим аккаунтом.
3. Создайте дополнение для самостоятельного распространения и загрузите ZIP. Текущий пакет содержит постоянный ID дополнения и декларацию об отсутствии передачи данных.
4. Пройдите проверки Mozilla и получите подписанный XPI. Рассмотрение может потребовать дополнительных действий или времени; подпись не гарантирована.
5. В `about:addons` выберите меню с шестерёнкой → «Установить дополнение из файла» и выберите подписанный XPI.
6. После установки проверьте правило и перезапустите браузер: дополнение и выбранные исключения должны сохраниться.

В этом проекте отправка пакета, принятие соглашений и получение подписи **не выполнялись**. Текущий ZIP подходит для разработки и подачи на подпись; это не готовый подписанный XPI. Не отключайте проверку подписей ради установки этой версии.

Источник: [Signing and distribution overview](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/).

## Если панель не появилась

- Обновите уже открытую вкладку после загрузки дополнения.
- Убедитесь, что открыта страница **группы**, а не преподавателя, на `https://my-rasp.tpu.ru/` или `https://ro-rasp.tpu.ru/`. Проверьте, что дополнению разрешён доступ к открытому сайту.
- Дождитесь загрузки читаемых названий предметов самим сайтом. При неработающей расшифровке расширение не создаёт правила для пустых названий.
- Проверьте сообщения дополнения в `about:debugging`. При ошибке хранилища страница показывает сообщение и не выдаёт неудачное сохранение за успешное.
- Firefox должен быть версии 142+; Zen — на Gecko 142+. Временная загрузка предыдущей сборки проверена в Firefox 159.0 и Zen 1.24b.
