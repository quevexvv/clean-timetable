# Установка в Chromium, Chrome, Edge, Brave, Opera, Vivaldi и Яндекс Браузер

Версия для браузеров на Chromium собирается из тех же исходников, что Firefox и Zen: разбор расписания, правила, хранилище и интерфейс не дублируются и не изменяются. Отличаются только манифест и точки входа.

## Сборка

```sh
npm ci
npm run build:chromium
```

Команда создаёт:

- `dist/chromium/` — распакованное расширение для локальной загрузки;
- `dist/tpu-schedule-filter-chromium-0.1.0.zip` — архив той же сборки.

Папка `dist/` создаётся при сборке и не входит в Git. Изменения вносите в `src/extension/` или `src/chromium/`, затем собирайте пакет заново.

## Локальная установка

1. Откройте страницу расширений браузера:
   - Chrome — `chrome://extensions`;
   - Edge — `edge://extensions`;
   - Brave — `brave://extensions`;
   - Opera — `opera://extensions`;
   - Vivaldi — `vivaldi://extensions`;
   - Яндекс Браузер — `browser://extensions`.
2. Включите **режим разработчика**.
3. Нажмите **«Загрузить распакованное расширение»** / **Load unpacked** и выберите папку `dist/chromium`.
4. Откройте или обновите страницу расписания группы на `https://my-rasp.tpu.ru/` или `https://ro-rasp.tpu.ru/`. Правила одной группы действуют на обоих сайтах.

После повторной сборки нажмите **«Обновить»** на карточке расширения и обновите вкладку расписания. Chrome не устанавливает ZIP напрямую: архив предназначен для распаковки или загрузки в магазин.

## Совместимость и разрешения

Поддерживается Chromium **109+**, включая стабильные Chrome, Edge, Brave, Opera, Vivaldi и Яндекс Браузер. В производных браузерах названия пунктов меню могут отличаться, но загрузка распакованной папки работает одинаково.

Расширение запрашивает только:

- `storage` — локальные правила и разовые пропуски;
- доступ к страницам групп на `https://my-rasp.tpu.ru/` и `https://ro-rasp.tpu.ru/` через `content_scripts`.

Доступа к другим сайтам, истории, cookies и сетевым запросам нет. Chrome может показать оба домена целиком в описании разрешения; скрипт запускается по шаблонам URL расписаний групп.

При обновлении установленного пакета Chrome может запросить доступ к `ro-rasp.tpu.ru`. Если браузер покажет запрос, подтвердите новое разрешение на странице расширений. [Документация Chrome](https://developer.chrome.com/docs/extensions/develop/concepts/permission-warnings#update-permissions).

## Чем отличается сборка

- Фоновый скрипт Firefox заменён на MV3 service worker `chromium-background.js`. Он загружает общий `background.js` после `chromium-compat.js`.
- `chromium-compat.js` создаёт совместимый объект `browser` поверх `chrome` и превращает Promise-ответ фонового обработчика в `sendResponse`, поэтому общий код не зависит от браузера.
- Из манифеста удалён блок `browser_specific_settings` и добавлен `minimum_chrome_version`. Content script получает `chromium-compat.js` первым.
- Service worker может выгружаться браузером; правило и данные остаются в `chrome.storage.local`, а сообщение со страницы снова запускает обработчик.

## Распространение

Публикация в Chrome Web Store, Edge Add-ons, Opera Add-ons или каталоге Яндекса требует отдельного поручения, аккаунта разработчика и проверки магазина. В этом проекте она не выполнялась. Для личного использования достаточно распакованной папки.

ZIP для Chromium не следует отправлять в Mozilla: для Firefox и Zen используется отдельный пакет `npm run build`.

## Проверка и ограничения

- `npm test` проверяет адаптер `chrome` → `browser`, преобразование Promise-ответов и сборку Chromium-манифеста.
- `npm run check` проверяет синтаксис общих и Chromium-скриптов.
- Запуск установленной сборки в Chromium пока не проверен. Проверьте загрузку `dist/chromium`, панель над таблицей, скрытие пары и сохранение после перезапуска вручную.
- Если панель не появилась, откройте `chrome://extensions`, проверьте ошибки service worker и доступ к сайту, затем обновите вкладку расписания.
