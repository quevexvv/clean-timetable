# Установка в браузерах на базе Chromium

[English](en/chromium.md) · [Firefox](firefox.md) · [README](../README.md)

Для установки нужен браузер на Chromium 109 или новее.

## Установка готового ZIP

1. Скачайте [Chromium ZIP из релиза v1.0.0](https://github.com/quevexvv/clean-timetable/releases/download/v1.0.0/tpu-schedule-filter-chromium-1.0.0.zip). Если архив уже скачан, переходите к шагу 2.
2. Найдите скачанный Chromium ZIP в папке загрузок и распакуйте его. Откройте распакованную папку и найдите `manifest.json`.
3. Вставьте адрес страницы расширений из таблицы ниже в адресную строку браузера и нажмите Enter. Включите **«Режим разработчика»**.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку с `manifest.json` целиком. **Clean Timetable for TPU** появится в списке расширений.

| Браузер                 | Страница расширений    |
| ----------------------- | ---------------------- |
| Chromium, Google Chrome | `chrome://extensions`  |
| Microsoft Edge          | `edge://extensions`    |
| Brave                   | `brave://extensions`   |
| Opera                   | `opera://extensions`   |
| Vivaldi                 | `vivaldi://extensions` |
| Яндекс Браузер          | `browser://extensions` |

## Как начать пользоваться

Перейдите на один из сайтов расписания, найдите свою группу и откройте её расписание. Если расписание уже открыто, обновите вкладку. Над таблицей появится панель **«Моё расписание»**. Чтобы скрыть пару, нажмите **«Настроить»** под ней и выберите **«Пропустить пару»** или **«Скрывать всегда»**. [my-rasp](https://my-rasp.tpu.ru/) · [ro-rasp](https://ro-rasp.tpu.ru/)

Если панель отсутствует, разрешите расширению доступ к сайту расписания и обновите вкладку.

## Сборка из исходников

```sh
npm ci
npm run build:chromium
```

В `dist/` появятся ZIP-архив и распакованная сборка `chromium/`. Для установки из исходников начните с шага 3 и на шаге 4 выберите папку `dist/chromium/`.

## Обновление

Распакуйте новый ZIP в папку установленного расширения или пересоберите его из исходников. Затем перезагрузите расширение на странице расширений и обновите вкладку с расписанием.
