# TPU Schedule Filter

## Стек
- WebExtensions Manifest V3, JavaScript ES2022, HTML5, CSS.
- Node.js 22.23.1, npm 10.9.8; тесты через встроенный `node:test`.
- `web-ext` 10.8.0 — зависимость только для разработки, с lockfile.
- Без UI-фреймворка, сервера и зависимостей во время работы.

## Планируемая структура
- `extension/manifest.json` — разрешения и подключение скриптов Firefox.
- `chromium/` — адаптер API и service worker для сборки Chromium; общий код не дублируется.
- `extension/core/` — чистая логика правил и адаптер локального хранилища.
- `extension/background.js` — единая очередь записи для всех вкладок.
- `extension/content/` — разбор расписания, интерфейс и стили.
- `tests/` — тесты логики, сборки Chromium и минимальные HTML-примеры расписания.
- `docs/` — установка и ручная проверка; `dist/` — собираемые пакеты.

## Команды
Команды реализованы в `package.json`; результаты проверок — в `docs/verification.md`.
- `npm ci` — установить инструменты из lockfile.
- `npm test` — выполнить `node --test` без изоляции файлов.
- `npm run check` — проверить синтаксис JS через `node --check`.
- `npm run lint` — выполнить `web-ext lint` для `extension/`.
- `npm run dev` — временно запустить расширение через `web-ext run` в Firefox.
- `npm run build` — собрать пакет через `web-ext build` в `dist/`.
- `npm run build:chromium` — собрать `dist/chromium/` и ZIP для Chromium из тех же исходников.
- Zen: `npm run dev -- --firefox /path/to/zen`; минимум Gecko 142.

## Контракты
- Постоянное правило: группа + предмет + преподаватель + тип занятия.
- Никогда не расширять его до всего предмета или всех типов занятия.
- Разовое действие привязано к календарной дате и времени начала.
- В ключах нет аудитории, номера недели URL или закодированных атрибутов.
- Полный вид не меняет сохранённые правила.
- Восстановление одной пары не отключает постоянное правило для остальных.
- Логику сопоставления держать отдельно от DOM; тестировать поведение.
- Интерфейс на русском; комментарии в коде на английском.
- Стили ограничивать областью расширения и расписания.

## Проектные ограничения
- Доступ только к расписаниям групп на `https://my-rasp.tpu.ru/`, `https://ro-rasp.tpu.ru/` и `storage`.
- Без аналитики, сетевой передачи правил, удалённого кода и доступа к cookies.
- Не вставлять недоверенный текст страницы через `innerHTML`.
- Не скрывать нераспознанные занятия по приблизительным совпадениям.
- Не менять серверное расписание, iCal и посторонние элементы страницы.
- Сборка Chromium не меняет файлы `extension/`; различия только в `chromium/` и генерируемом манифесте.
- Отправка пакета в Mozilla, Chrome Web Store, Edge Add-ons, Opera или Яндекс и публикация требуют отдельного поручения.

## Review guidelines
- Лекция, практика и лабораторная у одного преподавателя различаются.
- Другой преподаватель или группа не попадают под существующее правило.
- Разовый пропуск и восстановление не влияют на соседние даты и занятия.
- Учтены несколько занятий в ячейке, `rowspan` и повторный запуск скрипта.
- Оставшаяся пара занимает ячейку без лишнего разделителя и пустой половины.
- Сбой сохранения виден пользователю; быстрые действия не теряют данные.
- Результаты Node-тестов, DOM-проверок и установки в Firefox/Zen различаются в отчёте.
- Сохранение после перезапуска проверено отдельно от временной установки.
